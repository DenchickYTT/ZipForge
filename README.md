# ZipForge 🗜️

**ZipForge** — это простой, быстрый и безопасный архиватор для Windows с графическим интерфейсом, написанный на Python.

## ✨ Особенности

*   **Просмотр и редактирование «на лету»**: Добавляйте, удаляйте и переименовывайте файлы прямо внутри ZIP-архива без полной распаковки.
*   **Атомарная пересборка**: Все изменения применяются безопасно. Если что-то пойдёт не так, ваш оригинальный архив останется целым.
*   **Поддержка паролей**: Создание и открытие архивов, защищённых паролем (AES-256).
*   **Drag & Drop**: Перетаскивайте файлы и папки прямо в окно программы.
*   **Две темы**: Тёмная и светлая темы интерфейса.
*   **Мультиязычность**: Поддержка русского и английского языков (переключение на лету).
*   **Полная конфиденциальность**: Приложение работает **полностью офлайн**, не собирает телеметрию и не передаёт ваши данные.

## 🚀 Установка и запуск

Для работы приложения не требуется установка Python.

1. Перейдите в раздел [**Releases**](https://github.com/ВАШ_ЛОГИН/ZipForge/releases).
2. Скачайте последнюю версию файла `ZipForge.exe`.
3. Запустите файл. Готово!

> **Примечание:** Поскольку приложение собрано с помощью PyInstaller, антивирус может ложно среагировать на него из-за эвристического анализа. Это нормально для подобных сборок. При необходимости добавьте файл в исключения.
